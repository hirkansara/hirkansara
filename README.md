- بخش درباره ما و راهنمای عمومی معامله
- عنوان و توضیحات متا و داده ساختاریافته اولیه برای موتورهای جست‌وجو
- بدون نیاز به نصب یا فرایند build

## نمایش محلی

کافی است فایل `index.html` را در مرورگر باز کنید. برای تجربه بهتر توسعه، می‌توانید افزونه Live Server در VS Code را به کار ببرید. هیچ نصب وابستگی یا دستور build لازم نیست.

## انتشار روی GitHub Pages

1. وارد حساب GitHub خود شوید و یک مخزن جدید بسازید؛ مثلاً `hirkansara-website`.
2. فایل‌های این پروژه (`index.html`، `styles.css`، `script.js` و پوشه `assets`) را در ریشه مخزن بارگذاری کنید.
3. در مخزن به مسیر **Settings → Pages** بروید.
4. در قسمت **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب و **Save** را بزنید.
6. پس از تکمیل انتشار، آدرس سایت در همان بخش نمایش داده می‌شود. ممکن است چند دقیقه زمان ببرد.

اگر مخزن از نوع پروژه باشد، نشانی معمولاً به شکل `https://USERNAME.github.io/REPOSITORY/` خواهد بود. نام کاربری و نام مخزن را با مقادیر خودتان جایگزین کنید.

## پیش از انتشار نهایی

- نشان تصویری برگرفته از لوگوی ارسالی در سربرگ و پابرگ استفاده شده است. نسخه کامل لوگوی فارسی نیز در `assets/logo-hirkansara.png` قرار دارد؛ فایل‌های لوگو را در صورت نیاز با نسخه اصلی و باکیفیت‌تر جایگزین کنید.
- عکس‌های فعلی از Unsplash بارگذاری می‌شوند و برای نمایش به اینترنت نیاز دارند. برای کنترل کامل و سرعت پایدارتر، از عکس‌های مجاز خودتان استفاده کنید و فایل‌ها را در پوشه `assets/` قرار دهید.
- آگهی واقعی در سایت درج نشده است؛ بخش «ملک موردنظر شما» کاربران را به فرم مشاوره هدایت می‌کند. هر ملک را فقط پس از تأیید اطلاعات، قیمت، تصاویر و وضعیت مدارک منتشر کنید.
- نام مدیر، سابقه، مجوزها، اطلاعات مشاوران و شعار رسمی هنوز اضافه نشده‌اند؛ اطلاعات تأییدنشده را منتشر نکنید.
- پیوند نقشه، جست‌وجوی نشانی را باز می‌کند و مختصات دقیق دفتر را تضمین نمی‌کند. برای نمایش نقشه دقیق، لینک یا مختصات تأییدشده دفتر را جایگزین کنید.
- فرم فعلی اطلاعات را در سرور ذخیره نمی‌کند و فقط پیام واتساپ را آماده می‌کند. برای ذخیره درخواست‌ها یا پنل مدیریت، به بک‌اند یا سرویس فرم جداگانه نیاز است.
- فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ در صورت نیاز می‌توانید فایل فونت را به‌صورت محلی میزبانی کنید.
